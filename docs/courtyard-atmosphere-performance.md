# 全场红枫、雨后倒影与渲染预算

2026-10-25。用户已认可精细羽毛球章节，本轮保留其构图与动作。新要求是把红枫从庭院延伸到整个画面，形成枝叶探出墙外、经过镜头的感觉；进入羽毛球前逐步收回，并处理滚动卡顿与内存。

最新反馈进一步明确：停滚后仍需要持续风吹与落叶，叶片要有真实厚度和卷曲；树木和叶片需要更大，并用真实物理引擎落在文字笔画上。这覆盖上一版所有枝叶停滚定格、以及只沿预定轨迹飘落的规则；镜头、羽毛球和枝叶退场仍由滚动控制。

## 画面与动作

- 庭院左侧红枫整体尺度从 .8 增至 1.1，保留原枝干、根部与五裂树冠；右侧保留疏绿层次。
- 全屏前景枫枝与 18 片落叶共用庭院 renderer，前景有独立真实三维相机，无额外 WebGL context。桌面探枝尺度从 1 增至 1.65，枝上叶片也放大，数量从 180 减至 132 保留空隙；落叶单叶尺度由原 .13–.45 调为桌面 .7–1.1、手机 .38–.55，翻面与笔画承接可见。
- 近景叶使用 ambientCG LeafSet010 的 CC0 摄影轮廓和 PBR 细节，重建闭合薄壳、叶柄、几何脉络与卷边，正背面独立着色。单叶 2,180 三角、约 48 KiB 几何，叶长 1、卷曲深度约 .196、最薄壳 .0055；3 张本地双区贴图合计约 34 KiB。来源与改造说明在素材署名页公开，不冒称导入完整扫描模型。远处庭院树冠继续用简化实例叶。
- 窄屏采用更小、更高的探枝，不把桌面树冠等比压进姓名与研究巨字。落叶按投影位置在阅读区边缘柔和淡出；不逐帧读取 DOM，也不让小红叶擦过正文笔画。手机研究章的湿石倒影在标题上方消散，保留真实反射与正文留白。
- 左下章节导航按真实尺寸保留局部柔和留白，水面主体仍在门前；只在初始化/视口尺寸变化/恢复时读取导航布局，兼容 Chrome 200% 缩放，不在滚动帧读布局。成果正文与副证书题注错开，保留完整奖项与材料。
- 风场在可见时持续推进，混合缓慢阵风、叶面扑动、旋转和下落，不再依赖滚动才能落叶。仅环境风使用 30Hz 的空闲更新，滚动或鼠标请求立即进入下一帧。前景从 frame 900 到 1080 向右上收缩，生活入口不留红叶叠在球拍上；上滚恢复场景范围，风不倒放。隐藏时间不计入风场时钟，减少动态效果保持静态。
- 门前与院内的局部湿石用一次 768×512 平面反射，带轻微水纹与不规则边缘；没有全屏 SSR。建筑仍是真实三维推拉、穿门，门洞/书案/标签坐标不变。
- 成果章建筑独立淡出，枫枝继续留在边缘；羽毛球之前才随场景收回。单个有像素上限的合成目标完成主景淡出，不额外增加 bloom 链。

## 发现与修复

| 原开销 | 本轮处理 |
| --- | --- |
| 生活章庭院 opacity=0 后仍逐帧 render，鼠标也能重绘 | 章节 active、IntersectionObserver、页面可见性一起控制；隐藏时取消 RAF |
| 穿门时 CSS width/height 随每帧变化，ResizeObserver 重配 canvas | 全屏 canvas 尺寸固定，用 Three camera viewport 重现各屏幕构图；正常滚动不调用 setSize |
| frame、pointer、resize 分别绘图 | 合并到同一个请求帧；不重复提交同一浏览器帧 |
| 持续风场可能导致整个庭院与倒影每帧重绘 | 停滚后复用主景纹理，只重绘前景；相机/章节/尺寸变化才更新主景。风与滚动共享调度器，无第二条 RAF |
| 静态建筑每帧重算 2048 VSM 阴影与模糊 | 静态阴影缓存；首次就绪/恢复时重新生成，细叶影使用静态姿态 |
| 全分辨率体育半浮点 4× MSAA、透射、后处理深度缓冲 | 几何目标改 2× MSAA，透射尺寸系数 .25；去掉默认 canvas 的重复 AA 与纯后处理 depth |
| 未限定大屏 Retina 像素数量 | 两个主 renderer 均限制 280 万像素，DPR 上限 1.5；DOM 文字仍用原 CSS 字号 |
| 隐藏时仍保留大幅渲染目标 | canvas、主合成/后处理、倒影缩为 1×1；庭院阴影目标释放，返回时恢复 |
| 每次跨生活边界都卸载、解析全部模型 | 首次到达后保留已解析模型，暂停绘制；返回不重复解析/烘焙环境 |
| GLB 原始字节长期缓存、Bitmap 仅 dispose GPU | 解析完成删除 raw bytes Promise；卸载时去重 close 独占 ImageBitmap |
| 庭院叶片逐片非索引合并，水墨片元约 48 次 sin hash | 2,484 片树叶改为两个实例批次；水墨使用共享 128² 纹理、两次采样，最后 owner 释放纹理 |

先前实例化优化保留叶片密度，存储顶点从 585,516 降至 406,739，几何及实例缓冲从约 14.45 MiB 降至 10.55 MiB（约 27%）。更细的五裂叶使展开后模型三角形从约 195,172 增至 221,254；不把存储节省写成减面。该历史对照中非叶建筑、枝干与标签逐字节一致；本轮按用户要求放大左侧红枫，故不继续声称其枝干变换未变。

同口径的体育颜色缓冲配置预算：2048×984、旧 DPR 1.75 / 4× MSAA / 全分辨率透射约 623.86 MiB，新 280 万像素上限 / 2× MSAA / .25 尺寸透射约 133.50 MiB，约下降 78.6%。这是已配置目标的颜色附件估算，未含深度、canvas、阴影、模型与驱动，不是 GPU 总内存实测。Three 内部透射目标仍使用 4× MSAA；.25 是宽高比例，所以其像素数为原来的 1/16。暂停时画布与显式后处理目标缩为 1×1，内部透射目标可能仍保留约 7 MiB 颜色缓存，直到下次透射绘制调整尺寸。

## 可复现的检查与边界

开发预览带 `?renderAudit=1` 时，`.minnan-scene` / `.badminton-scene` 的 `data-render-audit` 提供绘制次数、缓冲重配次数、提交耗时、资源数量；新增 `backgroundDraws` 区分建筑/倒影与前景风场。停滚后前景 draws 应继续增长而 backgroundDraws 不变；离屏后两者均不增长。`data-render-state` 与 canvas width/height 可核对休眠。生产构建不输出该审计数据，无遥测和性能面板。

上一版 `281ff53` 的 Chrome 对照记录（持续风场的最新复验另记在评审文档）：

- 优化前首屏到实习，庭院重配次数 2→7；优化后同一路线重配次数固定为 2，绘制次数 93→155，实际穿门无缓冲重配。
- 优化前生活滚动期间，隐藏庭院绘制次数 262→332；优化后庭院停在 196，canvas 1×1，生活绘制 6→7 时庭院仍为 196。
- 旧原生 2048×1040、DPR 2 的体育缓冲为 3557×1820，约 647 万像素；新原生截图采样 2360×1186，约 280 万像素。上限也有单测覆盖。二者实际窗口高度不同，不将该数字写作同条件 FPS 对比。
- 显式 2048×1040 视口模拟实际 DPR=1；仅用于验证布局/重配/休眠，不能与原生 DPR=2 的 CPU 数字直接比较。提交耗时含 GPU 排队及首次编译，不等于帧率。JS heap 随 GC 变化，不把单次读数视作总内存降幅。
- 新增水面和前景增加了一次低分辨率反射与少量批次；不是零成本。真正收益是停掉隐藏场景、免除重复阴影/重配和限制辅助目标，未删除已认可的羽枝/线床细节。
- 上一版构建、9 项几何/接触/滚动/调度/像素预算测试及 diff-check 通过。`cb62c17` 持续风场版本构建和 12 项测试通过，主 JS gzip 361.92 kB，独立生活章 124.66 kB。这些数据是加入物理碰撞之前的版本。
- 最新 Chrome 视觉结论与逐轮修订见 `portfolio-research-review.md`。停滚时需要看到风与落叶持续推进，静止截图只适用于减少动态效果；离屏必须停止绘制。未声称真机、低端 GPU 或弱网测试完成。

## 最新字形碰撞实现

- 使用 [cannon-es 官方三维刚体引擎](https://pmndrs.github.io/cannon-es/docs/)，锁定 0.20.0。18 个动态叶体，每片 5 个薄凸体近似真实叶瓣和卷曲；碰撞计算与高精度可见网格分开。当前稀疏叶片只与字形接触，叶片之间不互撞，不声称是流体或柔性叶片仿真。
- 姓名与章节巨字使用浏览器实际字体绘制 alpha 掩码，再合并笔画实心矩形并挤出三维碰撞厚度。孔洞与空格保留。标题进入透视退场后移除碰撞；章节、字体、视口或入场位移改变后等待约 120ms 稳定，再采样实际位置，风帧不测量布局。物理上限 768 个笔画 box，字形提取以 512 为预算。
- 重力、风力、气阻、角速度、接触与摩擦由刚体系统求解。首次字形就绪时从实际上方笔画附近安排 3 片初始落叶，之后不在屏内重播或吸附。固定步长 1/60 秒，每次调用最多 6 步；隐藏清空累计时间，恢复不补跑。空闲前景仍以 30Hz 提交，滚动优先。
- 同一叶片对多个笔画小 box 的摩擦共享总预算，避免仅因字形分割更细而粘死。测试检查同一横笔画分成 1/8/16 块时都可由风吹离；接触后没有锁位、瞬移、取消碰撞或删除叶片。
- 独立 Chrome R1 发现复杂汉字凹角仍会积叶：仅水平风不能越过高处笔画。阵风现在同时施加向上与朝镜头方向的力，叶片翻起、离开笔画后再受重力落下；该力作用于所有叶片，不依赖接触时长。新增真实 Chrome 姓名的 230 个笔画碰撞体夹具，120 秒物理回归同时要求初始停留、阵风释放和后半程不堆积；这是确定性仿真测试，不是浏览器内存压力测试。
- 开发审计 `data-leaf-physics` 提供真实接触、支撑、步数、回收和 body 数；`data-render-audit.updateCpuP50/P95` 记录字形/物理/实例更新成本，原 `cpuP50/P95` 仅为绘制提交。两者都不是 GPU 帧率；生产无这些审计字段与计时。
- 本轮构建与 21 项测试通过：新增笔画落地/停留/吹离、字间空白、摩擦分割一致性、真实汉字多轮阵风释放、速度预算内薄笔画不穿透、不同调用频率一致、暂停与资源边界。主 JS gzip 390.61 kB，体育独立包仍 124.66 kB；保留既有构建提示。Chrome 最新视觉结论另记于独立评审文档。
