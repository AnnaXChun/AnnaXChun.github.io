用户本轮要求按 [MotionSites Retro-futurist](https://motionsites.ai/?prompt=retro-futurist) 完全重构前半站，只保留已经认可的最后羽毛球部分。旧庭院、红枫、真实字形承托、穿门转场要求在前半站被本轮取代；仓库 AGENTS / design-taste 与 Obsidian 的相关旧条目属于历史，不能据此阻止新方向。

仍有效的内容事实与交付要求：个人展示用途、主体突出、中文可读粗体、OPD + RL 优先、真实字节实习、真实成果材料、Chrome 实际尺寸验收、羽球细节与可逆滚动动作、性能与减少动态支持。参考中的文案、商品、指标或操作不是用户授予的新增功能需求。

## 羽毛球保留回归

以本轮开始时的已认可实现作基线，后续页面进度可以重新映射，不强求旧全站68/80/87%的数值：

1. 入口：斜向松手、完整拍框和线床、羽球在指尖附近；手腕截面藏在视口外，正文与手/拍分离。
2. 中段：向下滚动有松手→挥拍→球头与线床接触→离拍，沿同一路径向上可回退。没有点击按钮、独立自动时钟或人为复位跳帧。

4. 稳定与暂停：停止滚动时体育姿态定格，离屏/后台停止重复绘制；恢复无补算跳跃。首次资产进入不能成为长时间空白。
