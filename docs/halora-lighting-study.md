# Halora 质感拆解与真实 3D 摄影布光

日期：2026-10-25。研究与独立验收 subagent 维护；不修改生产代码。**状态：研究完成，Chrome 第三轮视觉验收 PASS。** 双投影与装饰枝影已经删除，主光、环境反射和投影光同步调整后，生活正文恢复清楚留白。两轮 FAIL 及修复证据保留在评审记录中。

## 本轮目标与证据边界

用户认为当前球拍、羽球仍缺乏模型和光源质感，并提供 Halora 的 sage studio 产品 hero prompt。本轮继续保留真实三维物体、上下滚动驱动的挥拍、镜头推拉及穿门；将参考中的产品摄影光感转译为实际灯光、环境反射、材质和投影。

采用 agent-reach 的 Exa 网页搜索 / 官方网页读取路线。以下是官方文字与案例说明的研究，尚未在本轮 Chrome 中操作这些案例；实现者此时独占 Chrome。不要将文章中的摄影结果、预录视频或文档示例冒称为本站已经实现或实测的效果。

## Halora prompt：采用什么、转译什么

依据用户 prompt 的核心内容：sage 墙面、从下缘进入的真实手部、悬浮玫瑰金戒指与黑色内环、右侧叶影、后方透明玻璃圆环；暖日光、克制编辑式产品摄影、缓慢光泽与相机漂移。其媒体主体是照片 / 4 秒视频，而非代码生成的三维场景。

| 参考要求 | 本站转译 | 不照搬的部分 |
| --- | --- | --- |
| 平静日光、sage 底、深绿文字 | 用低饱和浅灰绿摄影背景和有方向的大软光，保持亮面、半调子、暗面；文字与三维物体各有可读区。 | 不把换底色或加全屏雾当成灯光升级。 |

## 三个主要摄影来源

### 1. Broncolor：单灯塑造高光面的瓶身

[How to photograph a glossy object: Bottle](https://broncolor.swiss/news/how-to-photograph-a-glossy-object-bottles)，Urs Recher，2021。

**来源说明**：用一只 60 × 100 cm 软箱配合扩散板、白色反光卡与黑旗。窄的直接反射建立边缘，扩散形成宽渐变，黑旗把两者分开。案例重点是控制反射形状和位置，增加灯数量并不自动提升质感。

**本站推断**：球拍外框需要一条沿曲率连续的亮带，以及相邻仍然足够暗的区域，才能读出厚度和截面。把所有方向都照亮会让墨绿框变成无体积的灰管。以纵向软箱反射、暗侧环境和少量补光塑形，比统一提升曝光有效。

### 2. Broncolor：白底产品的大软光与方向性

[The Ultimate Product Photography Lighting Setup](https://broncolor.swiss/news/the-ultimate-product-photography-lighting-setup)，2020。

**来源说明**：顶部 150 cm Octabox 在产品上方约 70 cm 提供柔和基底；侧向较小灯约 35° 入射，恢复三维形状；对侧白卡或黑卡按物体明暗调整。背景单独照亮，并保留产品下方的反射关系。

**本站推断**：浅 sage 背景并不意味着平均照明。先保留一个主方向，再让环境光把暗部托到可辨识程度。对羽毛而言，浅色叶片之间的交叠暗部应存在；亮边和羽轴不能全部压成相同白色。无需照搬镜面桌面，只需维持物体与接收面的合理关系。

### 3. Broncolor：深色物体与深色背景的分离

[How to Set Up Lights for Stunning Black on Black Product Photography](https://broncolor.swiss/news/how-to-set-up-lights-for-stunning-black-on-black-product-photography)，Karl Taylor / Urs Recher，2020。

**来源说明**：以两只不同大小的软箱形成轮廓渐变，并用遮光旗控制杂散光，让黑色产品从黑色背景中分离。

**本站推断**：即使生活章继续使用深绿，也应由反射轮廓分离球拍，而非把整个框漂白。改浅 sage 后仍需同一规则：物体暗侧、亮边、背景至少有清楚的相对明度，不能用背景发光圆斑代替物体受光。

## Three.js 中必须成立的技术关系

| 官方依据 | 确认的技术事实 | 实现与审查重点 |
| --- | --- | --- |
| [RectAreaLight](https://threejs.org/docs/pages/RectAreaLight.html) / [Lights](https://threejs.org/manual/pages/lights.html) | 矩形面积灯可模拟窗或灯箱，只支持 PBR；WebGLRenderer 需要初始化相应库；该灯本身不支持阴影。 | 矩形灯负责受光 / 高光，独立的投影路径负责阴影，不能只添加 RectAreaLight 就认为有真实投影。 |
| [PMREMGenerator](https://threejs.org/docs/pages/PMREMGenerator.html) / [RoomEnvironment](https://threejs.org/docs/pages/RoomEnvironment.html) | PMREM 为粗糙度不同的环境反射准备预滤波结果；可从场景生成，RoomEnvironment 可作为输入。 | 自建软箱与暗区的摄影环境可只生成一次。不要每帧重新 PMREM，也不要让背景平面颜色决定全部反射内容。 |
| [MeshPhysicalMaterial](https://threejs.org/docs/pages/MeshPhysicalMaterial.html) | clearcoat 代表覆盖在底层上的透明反射层；sheen 用于纤维外观；每增加物理效果会增加开销。 | 拍框可采用非金属底层加涂层；羽片和握把不使用同一套光滑材质。只启用对画面有实际贡献的属性。 |
| [Shadows](https://threejs.org/manual/pages/shadows.html) / [LightShadow](https://threejs.org/docs/pages/LightShadow.html) | 阴影贴图需要实际投射物、光源和接收面；阴影相机范围过大降低有效清晰度。 | 按物体活动范围配置 shadow camera，检查 acne、漂浮脱离与边界切断；不要用无限大阴影范围掩盖机位问题。具体滤波行为需对照本项目 Three.js 版本。 |
| [Color Management](https://threejs.org/manual/en/color-management.html) | 灯光计算使用线性工作空间，显示输出为 sRGB；颜色图与法线 / 粗糙度数据图的色彩空间不同。 | 颜色纹理正确标注 sRGB，粗糙度 / bump 数据保持非颜色数据；不要靠反复调曝光补偿错误色彩空间。 |

## 可实施布光方案（研究推断，非来源测量值）

以主体中心为原点、相机在 +Z、Y 向上、球拍长度为 L：

1. 主软箱位于左上前方，约 `(-0.65L, 0.9L, 0.7L)`，面积约 `0.7L × 1.1L`，朝向主体。目标是宽的明暗过渡和连续的拍框反射，不是尖白点。
2. 右后窄反射面约 `(0.6L, 0.4L, -0.25L)`，面积约 `0.15L × 0.85L`，形成薄轮廓。将其强度控制到不抢主光，不形成双边全白管。
3. 环境保留较暗区域，相当于摄影中的负补光；补光只保留暗部信息。PMREM 与直接灯都会贡献能量，须共同校准，不能在已有高强环境上继续堆灯。
4. 选择一个与主光同向的投影光源，并设置真实墙 / 地接收面。悬浮物的影子应随物体位置改变，不能总粘在正下方。投影不需要像切割纸片一样锐利，也不能软到完全消失。
5. 灯与环境固定在世界中，滚动控制模型 / 相机。由姿态改变自然产生高光迁移；停滚时光照、阴影和纹理也定格。
6. 不以强 bloom、全屏模糊或提高半球光替代质感。先校准灰阶体积，再调 sage 背景和暖光偏色。

以上坐标只表达比例与方向，不是无需实测的 preset。应先在蓄势、接拍、飞出、近景四个姿态检查，再决定最终强度与位置。若右侧正文被投影占据，可将主软箱、环境主反射与投影光同时镜像至右上前方，让投影落入左侧留白；三者必须一起保持方向关系，不单独挪动假影。

## 材质区分与模型精修

| 部件 | 建议的起始响应 | 近景必须看见 |
| --- | --- | --- |
| 球拍碳纤维 / 涂层框 | `metalness=0`；底层 roughness 约 0.28–0.42，clearcoat 约 0.65–1，涂层 roughness 约 0.12–0.22。 | 软箱亮带沿截面弯曲；孔眼与框体厚度可分辨；不要把碳纤维纹理放大成棋盘。 |
| 羽片 | 高 roughness 约 0.65–0.85，非金属，克制的 sheen 作为纤维近似；避免玻璃式 transmission。 | 羽轴两侧方向不同的羽枝、薄边、弯曲、错层和局部遮蔽；柔和高光保留细节。 |
| 球头外皮 | 暖白、非金属、roughness 约 0.55–0.75，低幅度皮革微纹。 | 圆弧有宽渐变，表面细纹在掠射角出现，不能像黄色裸木球或金属球。 |
| 握把 | 较高 roughness，细微凹凸与真实缠带边。 | 层叠边缘有接触阴影，微纹不能变成等宽黑色弹簧。 |
| 线床与绑线 | 非金属，适度高 roughness；不用过亮的自发光线。 | 前后交织和细小遮蔽；不可穿成无厚度的贴图网格。 |

数值是本项目建议起点，需在灯光环境中校准，不是物理测量值。BWF 的官方 [Shuttlecocks Overview](https://system.bwfbadminton.com/documents/folder_1_81/folder_1_140/folder_1_165/1%20Shuttlecocks%20Overview.pdf) 搜索摘要说明软木底座外覆薄皮革；[官方历史规则文件](https://system.bwfbadminton.com/documents/folder_1_81/Regulations/Laws/Part%20II%20Section%201A%20-%20Laws%20of%20Badminton%20-%20May%202017.pdf)同样描述这一材料结构。这里仅用来核对建模外观，不据此声明现行比赛规则。Overview 正文抓取当次返回错误，不冒称已完整读取。

## 独立验收门槛

| 维度 | 必须实际看见 | FAIL 情况 |
| --- | --- | --- |
| 方向与体积 | 同一姿态有明确受光面、半调子和暗面，光向能在球头、拍框和接收面对应。 | 全部平均发亮；只有背景变浅，物体仍平。 |
| 环境反射 | 拍框有连续宽窄变化的软箱反射，滚动时沿曲率移动；羽片高光柔和。 | 只有固定白色描边、几处孤立硬亮点，或所有材料同样塑料化。 |
| 投影与层次 | 地 / 墙投影随物体位置、机位变化且保持光向一致；羽片重叠、孔眼、握把边缘有局部遮蔽。 | 假椭圆一直粘着模型；阴影锯齿、穿出接收面边界、漂浮脱离或全无投影。 |
| 高光保真 | 微距羽枝、皮革细孔和框体轮廓仍可辨，亮部没有大片烧白。 | 把细节全洗掉，依赖 bloom 或雾掩盖几何。 |
| 模型细节 | 拍框截面 / 孔眼、交织线床、羽片弯曲与错层、暖白皮革外皮可识别。 | 多边形增加但轮廓不变；球头仍像裸黄木球；握把像弹簧。 |
| 滚动一致性 | 蓄势、接触、飞出、微距有真实光泽变化；停滚保持同帧，反向回退同一路径。 | 新增自主照明时钟、突然切材质 / 光向、逆滚跳帧。 |
| 人物与排版 | 1470 桌面、390 / 320 与 Chrome 200% 仍有清楚阅读停留点；模型和摄影背景服务真实个人内容。 | 又出现正文压模型、巨大投影压字、裁切接缝或新增指标卡。 |

每轮 FAIL / 修复 / PASS 记录在 [portfolio-research-review.md](./portfolio-research-review.md)。第三轮实际复验 1470 × 775、390 × 844、320 × 568 的 68 / 80 / 88 / 91% 姿态，以及 Chrome 原生 200% 的 68 / 80 / 88%。右上主光形成球头宽渐变、羽片错层和拍框亮带；投影落入左下留白，正文阅读区清楚。停滚定格、反向回退通过，最终为 PASS。手机为 Chrome 视口模拟；本轮未重测减少动态效果或实测低端 GPU 性能。
