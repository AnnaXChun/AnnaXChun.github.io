## 当前方向

唯一主要视觉参考：[MotionSites · Retro-Futurist](https://motionsites.ai/?prompt=retro-futurist)。Chrome 中可见：大尺度 CRT 电脑头人像、冷灰摄影背景、黑色粗体、白色 pill、稀疏 UI 和微动。复现它的构图、材质关系和节奏，不复制品牌、商业功能或未经授权的付费源码。参考提示词的复制按钮可用，但本次浏览器未返回文本；只依据实际可见画面研究，不声称取得原始实现。

- 首屏：原创建模感摄影插画，电脑替代人头，羊毛西装、旧塑料与玻璃反射形成材料对比。主体占据右侧并出画，左侧职业与研究方向直接可读。透明素材允许前后层视差，头部以颈部为轴独立透视转向，眼睛注视与身体有不同缓动、眨动；不可把照片宣称为真实三维模型或本人照片。
- 后训练：深石墨色整页、大幅 OPD + RL、一个醒目的 SOTA 圆章；只呈现用户确认的经验，不造评测图或分数。
- 字节经历：大号英文标题与中文真实事实，四行开发工作，不做虚假的终端/仪表盘。
- 成果：两幅原始证书优先，正文下方有完整成果档案和更多项目，使用原生 details/dialog。
- 个人：保留本人原有手绘肖像、教育、兴趣和公开联系。字体全部基线 700，主文 16–20px，不按画布等比缩小。
- 羽毛球：完全保留接受的导入精细模型、摄影光照、手部放球与滚动挥拍、掠镜、反向还原；保持冷白/冰蓝体育空间，作为最后一个视觉章节。
- 不恢复顶部框状 banner，不添加购物、阅读模式、播放控制、比分或功能性 Agent 聊天界面。

## 动效与资源

GSAP ScrollTrigger 负责章节入场和连续视差，只更新 transform/opacity；不每帧重渲染 React。研究以真实摄影磁带盘作为前景，随滚动旋转、随鼠标倾斜；实习四项工作使用有深度和错位的文件卡片，事实保持直接可读。避免只有文字的平铺叙述。

前半页不挂载古厝、树叶物理、字形 Worker。体育在接近其章节时再加载；继续原有有界绘图缓冲、shader warmup、离屏/后台暂停。减少动态效果关闭入场/视差/眨眼，体育静止，内容不丢失。

手机使用文字与摄影主体的自然文档流，避免绝对定位相撞。完整内容不隐藏在必须滚完的全屏长动画中。证书不裁切，窗口可 Escape 关闭、返回原焦点。原生滚动与键盘有效。
