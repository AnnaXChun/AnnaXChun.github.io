# 椿襄个人网站 · Design taste

更新：2026-10-31。用户本轮要求「不要搞这么工业化风格，其他个性的比如宫崎骏那种的」。当前手绘动画方向覆盖10月28日CRT/金属磁带盘/灰色摄影棚；旧庭院、红枫、物理落叶和穿门也不恢复。保留已经认可的最后羽毛球章节。

## 当前审美

通透的蓝天、山丘与小屋，绿围巾的原创森林信使；清楚的颜料笔触、草木色和自然光。角色是有性格的同行者，页面像研究与生活的旅行手记，不做工业产品海报。灵感是用户指定的手绘动画电影气息，不直接使用既有电影角色、商标或官方画面。

- 首屏：风景为远景，人物为前景，标题直接可读。头部独立透视随鼠标转动，身体低幅跟随；滚动时文字、人物与风景有不同速度。触屏不劫持滚动，减少动态时完整静止。
- 研究：OPD + RL 大字、夹着叶子的纸飞机、朱红SOTA邮戳。纸飞机轻倾斜并随滚动向前上方移动；排版留足文字空间，不伪造图表、分数。
- 实习：手帐便笺表达四项真实工作，不把信息藏在交互里。中文主标题，克制的胶带、错位与薄纸层次。
- 成果：原始证书完整contain显示，有足够主体面积；可键盘打开dialog、Escape关闭、返回原焦点。
- 个人：原有手绘肖像、教育与生活介绍。正文16–20px/700，标题粗宋体、大而清楚；配色以深绿文字搭配浅蓝绿、淡纸白，避免低对比浅灰或整页黄褐。
- 羽毛球：原导入模型、PBR光照、放球/挥拍/触球/掠镜及反向路径全部保留，保持冷白冰蓝的运动空间。
- 联系：浅森林绿，像留一封信，真实email/GitHub/电话；不加商城、阅读模式、游戏控制、聊天机器人或框状banner。

顺序：身份 → OPD + RL / 开源benchmark SOTA → 字节国际商业化Agent实习 → 原始成果 → 个人生活 → 联系。

职业：Agent开发、后训练算法工程师。字节实习2026.09.20—至今，Claude Code内核接入内部Agent、业务流程适配、Skill优化、Bad Case Studio。用户不要求具体benchmark名称和分数，不追问、不编造。事实源`pages-site/src/data.js`。

## 工程与验证

GSAP ScrollTrigger，主页面只有transform/opacity动画，无React逐帧更新或每次scroll读layout。不启动旧树叶物理/字形Worker；手绘页面使用DOM图层。性能充足桌面可在首屏就绪后的空闲期初始化同一个体育场景，以1×1目标预热一次后暂停，模型内存会更早持有；节省流量、慢网、低内存、触屏或reduce仍在临近体育时加载。正常像素预算和离屏/后台暂停保留。纯视觉素材aria-hidden，不影响阅读顺序。

Chrome默认尺寸、1440、390/320、900–1200与真实200%检查；手机自然文档流，不用缩小桌面画布。检查中间运动帧与稳定阅读点、头身接缝、纸飞机与文字、证书和体育衔接。独立评审见`storybook-review.md`；旧retro审查只作历史，不沿用PASS。构建和测试不代替视觉判断；不把rAF间隔称作GPU FPS。
