# MotionSites：滚动、镜头与文字空间研究

日期：2026-10-25。针对用户新要求：**上下滚动驱动挥拍、模型更精细、文字参与前后景和镜头，而非固定左侧面板**。上一轮点击挥拍版本的 PASS 不适用于这轮要求。

## 来源核实与观看方式

本轮使用 agent-reach 的一手网页路线，检索后在 Google Chrome 直接查看 MotionSites 页面及其公开演示。采用 [MotionSites.ai](https://motionsites.ai/)：首页、[3D 目录](https://motionsites.ai/3d-websites)、[Academy](https://motionsites.ai/academy) 彼此链接；页脚列出运营者 Viktor Odainyi，并链接 [YouTube @ViktorOddy](https://www.youtube.com/@ViktorOddy)。没有把搜索中出现的同名 `.org`、`.dev`、单数 `motionsite.ai` 自动视为同一来源。

目录卡片初次只显示 poster，video 的 readyState=0、currentTime=0，不能算看过动效。我读取对应可见卡片的公开 video src，在 Chrome 新标签页打开原始 MP4；确认 readyState=4、实际播放，然后通过原生播放器进度条查看关键时刻。下列是**官方案例演示录像的实际观察**，不是可操控的原站本体；未宣称已测到原站滚轮回调、触摸行为或真实相机参数。没有打开付费代码、没有执行网页 prompt，也没有将网页内容当作操作指令。

## 案例一：Sky Cookie

[官方案例](https://motionsites.ai/3d-websites?prompt=sky-cookie) · [公开演示视频](https://pub-86dc5b5484314368ac5436a674b0d919.r2.dev/a/skycookie.mp4)

Chrome 实测视频长度 6.1 秒。以下秒数是录像时间，不是原站的滚动百分比。

| 观察时刻 | 实际看到的画面 |
| --- | --- |
| 约 0.1–0.6s | 大标题居中横跨上部，饼干在中间，天空和云为后景，两侧下沿有岩石。模型有可识别的厚度、粗糙表面和巧克力块。 |
| 约 0.98s | 标题的字母分别旋转、错开并飞出上沿；下一段标题从画面底部透出。饼干同期转向侧面，中心主体没有被换成另一张图。 |
| 约 1.5s | 新标题落在底部，饼干翻到另一面并保持居中。背景由高空转向花地，前景地面增多。 |
| 约 3.1s | 四处简短说明围绕模型出现；说明让开中央模型，文字和模型没有同时塞满同一块区域。 |
| 结尾 | 画面回到起始标题、饼干正面与天空构图。录像显示前进后返回的过程；不能仅凭录像断言底层实现方式。 |

**可采用的规则（本项目设计推断）**：滚动首先让标题退出，再让羽球/球拍动作占据中央，最后才出现下一段说明。物件的姿态持续变化，避免用淡入淡出替代整段运动。标题至少有一次从中景向近景掠出屏幕的过程；不能只是对固定左栏做透明度动画。反向滚动应恢复同一物件的先前姿态。

不采用其营销顶栏、玻璃按钮和食品配色。本站仍使用纸白、墨色与朱砂。

## 案例二：Feathers Atlas

[官方案例](https://motionsites.ai/3d-websites?prompt=feathers-atlas) · [公开演示视频](https://pub-86dc5b5484314368ac5436a674b0d919.r2.dev/designs/feathers-atlas-3d.mp4)

Chrome 实测视频长度约 5.93 秒。这是模型查看器操作录像，**不把它认定为滚动驱动案例**；其价值是模型精细度、近远景尺度和遮挡。

**实际观察**：纸白底，中央鸟类模型，右侧信息栏。正常视图中模型约占中间区域的三分之一；约 2.8s 的近景中，鸟头、翅膀和喙扩大到超出画框，翼尖与喙跨过后方信息栏。羽毛有层叠宽窄、不同弯曲方向、细密斑点和绒毛区，轮廓没有被统一模糊。末尾退到较小的另一只鸟，右侧文字重新完整可读。模型下有弱接触阴影，空白本身维持空间感。

**可采用的规则（本项目设计推断）**：让镜头真正接近羽球球头、绑线和羽根，近景允许羽片越过画框、遮住后景巨字。细节要支撑这次放大：羽片需有不等宽轮廓、羽轴与羽枝、轻微弯曲与错层，球拍需有穿线孔、交织线床和握把缠带。说明正文在近景退场，不能一面被模型遮住一面要求访客阅读。

不采用其侧栏、物种筛选、缩放按钮或蓝橙配色。它的长期文字遮挡也不应照搬：本站只允许在短暂转场中遮挡，必须有能读完整事实的停留段。

## 案例三：Michelle 3D portfolio

[官方案例](https://motionsites.ai/3d-websites?prompt=michelle-3d-portfolio) · [公开演示视频](https://pub-86dc5b5484314368ac5436a674b0d919.r2.dev/designs/michelle-3d-portfolio.mp4)

Chrome 实测视频长度 7 秒。视频一次加载超时后通过已创建的标签页重试成功。

| 观察时刻 | 实际看到的画面 |
| --- | --- |
| 约 0.1s | 姓名巨字横跨上方，短简介在下方，下一行大字从屏幕底部进入。整个画面使用高对比黑白，而不是小字卡片。 |
| 约 2.5s | 文字块倾斜成为前景墙面，左侧部分字被镜头裁出；后方仍有较小的一层文字，产生清楚的透视差。 |
| 约 3.5s | 近处巨字掠过画面边缘，下一页作品列表位于中央远处，周围大量留白像一个通向下一页的空间。 |
| 约 4.4s | 作品列表被推近，恢复正常可读比例；作品名称、图与说明重新建立稳定对齐。 |
| 约 7s | 巨型联系句占据上方，邮箱在右下，底部是独立物件；信息位置随章节变化。 |

**可采用的规则（本项目设计推断）**：上一章节的关键词可以成为离镜头很近的边缘，而下一章节的事实先在远处出现，再被推近到可读位置。摄影式构图来自三个层级的相对变化：近景的局部裁切、中景的主体、后景的下一段；不是把同一面板在左右之间切换。运动中允许标题截出边界，落点不能截断身份、实习时间或研究信息。

## 给本轮实现的直接约束

这些是基于案例的设计方案，不冒充案例源码或实测参数：

1. **一个可逆时间轴**：用生活章滚动进度统一驱动蓄势、拍面接触、羽球加速离拍和远景收束。停住滚动就保持同一动作相位，反向逐帧返回；删除“挥拍”按钮和独立时钟。
2. **三个空间层级**：后景是一至两个超大关键词；中景是球拍与羽球；前景只保留一组短说明或掠镜大字。不同章节的说明可落左下、右下或中央远处，不固定同一侧。
3. **两种尺寸跨度**：既有能同时理解球拍/球的全景，也有球头、羽根或线床占画面大半的近景。近景由真实相机/物体位移和透视完成，不以模糊和整块画布缩放替代。
4. **运动段与阅读段分开**：运动时让正文退场；进入稳定构图后恢复职业、OPD + RL、字节实习及日期的正常阅读尺寸。不要把所有信息都变成三维纹理。
5. **材质经得起放大**：羽片细分与错层、羽枝、绑线、软木表面、球拍穿线孔和握把缠带必须在近景可辨。单纯增加不可见的多边形不算精修。
6. **色彩克制**：延续既有纸白/墨绿/朱砂，与闽南庭院保持同一视觉语气；参考的是运动和空间规则，不是照搬别站的色彩或产品功能。

## 新一轮验收门槛

- 上下滚动能决定完整击球过程，停滚不继续播放；反向恢复，不靠按钮或点击。
- 至少看见一次有因果关系的拍面接触和离拍；途中没有穿模、瞬移或球拍挥空。
- 至少三个不同的文字落点/空间角色，且有一次清晰的近景/后景交接；不能用所有章节同一左栏凑数。
- 有实物极近景，能看清本轮新增细节；画面允许局部出框，但核心阅读落点无裁字或遮挡。
- 390 / 320 宽与 Chrome 200% 仍能读完整身份和经历，滚动自然、没有巨字造成横向溢出。
- 真实闽南庭院及穿门仍保留，OPD + RL 仍是重点，字节经历仍忠实于用户确认内容。
- 减少动态效果保留静止场景和完整事实；上一轮 PASS 只作为历史记录，必须按新要求重新审查。
