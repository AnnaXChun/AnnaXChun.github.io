## 本轮依据与历史边界

用户最新要求是放弃工业风，改为类似宫崎骏动画的、更个人化的手绘动画方向。本轮拟实施清透蓝天、草木绿、手绘山丘与小屋、原创森林信使、研究纸飞机与旅行手记、实习手帐。用户此前认可的最后羽毛球场景保持原样。

已按记忆协议读取 Memory Dashboard、项目索引与个人简历网站页，以及用户档案中的工程/产品视觉偏好。当前 Obsidian、仓库 AGENTS 和 design-taste 仍记载 10 月 28 日的 retro-futurist 方向，落后于本轮明确要求：CRT、西装、磁带盘、工业摄影语言均不再是新版门槛。旧庭院、枫叶、真实字形碰撞也不恢复。旧评审记录保留为历史，不能拿任何旧 PASS 证明新版完成，也不能把旧 R8 未验收作为新版必须修完的前置工作。

本轮可以使用手绘分层素材与 2.5D 透视来表现空间，不要求前半站改回真实三维建筑；不得把分层插画说成真实 3D 模型或本人实拍。羽毛球仍是原有真实 3D 场景。

这里的审美判断是依据本轮意图制定的实施标准，不声称已经观看某部动画的逐帧参考，也不以具体导演或工作室名称代替可验证的画面要求。

## 必须成立的设计判断

| 范围 | 可见的通过条件 | 需要返工的表现 |
| --- | --- | --- |
| 整体语言 | 开阔天空、自然草木、手绘线与色块共同构成一个有光线、有空气的世界；身份文字仍是明确的阅读入口。 | 给旧 CRT / 磁带 / 文件卡换暖色；大面积泛黄纸、统一模糊滤镜；仍像工业产品官网。 |
| 首屏主角 | 森林信使有易辨的剪影、表情与携带物，像在观察或准备出发；它与小屋/山丘有尺寸和空间关系。主体足够大，缩小截图仍能识别角色。 | 角落里的小吉祥物、无目的上下漂浮、背景壁纸加一枚贴纸；套用现成影视角色，导致用户本人被角色品牌淹没。 |
| 场景深度 | 天空与远山较轻、屋舍/路径为中景、角色与少量草叶为前景；遮挡、接地阴影、运动差速一致。静止帧本身也有层次。 | 全部图层同速横移，靠放大或模糊制造深度；角色悬空、阴影方向冲突；前景遮住核心文字。 |

| 头身交互 | 真实指针左右/上下移动时，角色整体有明确转向或侧倾，头、眼、身体有适度差速；退出角色区域自然回中。 | 只有眼睛动；只有整张图片平移；头身接缝裂开、残留旧轮廓、眨眼穿过脸、旋转后露硬边。 |
| 色彩与光 | 清透蓝天、明亮草木与少量纸色互相区分；暗部仍有颜色，文字用深墨绿/深蓝等可靠对比。 | 全页奶油黄、灰棕低对比；过曝光晕吃掉角色或文字；用大片荧光绿替代自然层次。 |

| 实习手帐 | 四项具体工作直接可读，纸张错层、页签、铅笔注记只辅助组织；视觉与研究的旅行手记同源但有不同构图。 | 一排同规格带阴影卡片换纸纹；满页装饰标签、假终端、聊天机器人、密集流程板；必须翻页才能读到已确认事实。 |
| 真实成果 | 原证书保留完整比例和可点开的原图，题注相邻。可借画夹/册页框定，但不改动证书内容。 | AI重画证书、复古滤镜压掉真实文字、裁掉奖项或姓名；封套/贴纸抢走材料主体。 |
| 个人与联系 | 本人肖像、教育、研究/实习身份和兴趣可直接找到；联系入口明确且不承担装饰任务。 | 森林信使被当成本人照片；全部个人事实藏在翻页、悬浮或点击彩蛋后；为了主题补造经历、地点、语录。 |

判断“有性格”时先看三张无动效截屏：首屏、研究、实习。三张应像同一个人的世界，但有不同的主物件、视线方向和信息布局；不能只靠动画、换底色或一套重复卡片成立。

## 信息、字体与操作门槛

内容顺序保持：姓名与职业 → OPD + RL / 开源 benchmark SOTA → 字节实习 → 真实项目/成果 → 本人和生活 → 联系。

- 姓名：椿襄。职业：Agent 开发、后训练算法工程师。
- 字节跳动国际商业化部门 Agent 开发实习：2026.09.20—至今；Claude Code 内核接入公司内部 Agent、业务流程适配、Skill 优化、Bad Case Studio。
- 只呈现用户确认的 benchmark SOTA 经历，不补造 benchmark 名称、成绩、排名图、增长百分比或公司内部业务数据。`src/data.js` 继续作为事实来源。
- 中文主文以 16–20 CSS px、700 字重为基线；核心角色通常至少 18px。手写字适用于短标题/旁注，不应用难辨字体承载整段专业信息。
- 通过自然重排适配手机和 200%，不能把桌面整张画布等比缩小。标题允许有前后景，但完整阅读点必须可辨，不靠用户猜测被遮住的字。
- 稳定阅读区不得被近景叶片、角色、飞机、纸角遮挡；入口/中段/退出都要检查，不能仅截最整齐的一帧。
- 纯装饰不伪装成按钮。链接、证书预览、原生 details 保持语义和焦点可见，Escape 关闭并返回原触发项；键盘、原生滚动和锚点正常。
- 不恢复框状顶栏、静态阅读模式、游戏分数、对话窗口、播放按钮、商城指标或背景音乐等无关功能。

## 动效与性能门槛

环境可以轻微呼吸、草叶轻摆、云缓行，但一次只保留少量注意力焦点；角色的注视应回应指针，飞机应回应滚动，不让所有东西同时自动运动。静止时正文稳定，允许随时中断和反向。

前半页的空间感可由素材分层、transform/opacity 和轻透视组成。代码审查要检查监听/observer/tween清理，避免 React 每帧状态更新与滚动时反复测布局。复用已实现的 GSAP 生命周期与体育资源管理，不为了新主题重挂载旧庭院、物理或后处理。

- 停止输入后，非必要持续动效收敛；离屏与后台停止环境循环和体育重复绘制。
- `prefers-reduced-motion` 实际启用时，关闭角色跟随、入场飞行、视差与环境循环，所有事实、材料和联系仍完整可读；体育静态展示。
- 手机没有 hover，角色与场景仍能在静止状态表达性格；不要求触摸拖拽才能解锁内容，不能劫持纵向滚动。
- 照片/手绘素材加载后不得造成大幅跳位或长期空白。透明切边在深浅底上都要干净，避免光圈白边、错位阴影和接缝。
- 真实流畅度独立验收。构建、单测、素材压缩率和库名都不能代替滚动观察；rAF 间隔、主线程长任务、CPU提交与 GPU 呈现帧率分开表述。

## 问题分级与交付判定

- P1：主要信息/操作无法到达、关键渲染失败、强制交互导致无法阅读。
- P2：主题仍是工业页面换皮、角色没有可见性格/空间回应、关键文字遮挡、图层接缝、手机/200%不可读、体育明显退化、持续动效违反减少动态等。修复并定点复验后才能 PASS。
- P3：不影响理解与交互的局部精修，可记录建议；不能用大量P3稀释真正的设计问题。

最终PASS只覆盖真实检查过的新版版本和状态。没有实体手机、弱GPU、弱网或长时间内存测试时明确边界。独立视觉PASS不等于用户已认可，也不等于公开部署完成；上线由主代理核实。
